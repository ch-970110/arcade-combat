# arcade-combat (PVP Arcade)

A Processing (Java mode) PVP arcade fighting game. "PVP Arcade" and "Arcade Combat" were two names for the same project.

```
arcade-combat/
├── Arcade_Combat_v1_6_1/   latest game sketch (.pde) + item/icon images
├── prototypes/             Arcade_Combat, Arcade_Combat2_0, Arcade_Combat_3_0, FobVideoPlayer, Video_to_Frame_test_3_0 (code only)
├── version-notes/          notes for older versions (v1.5.2 ... v1.5.7 etc.)
├── design-assets/          CoD Icons, Equipments, design docs, poster
└── PROJECT_LOG.md          version history
```

## Not stored in git (too big for GitHub)

- Animation frames: ~10,600 PNGs in `Arcade_Combat_v1_6_1/data/` (~1.8 GB). Regenerate them with `prototypes/Video_to_Frame_test_3_0`.
- `Characters/` character design art (~3.7 GB), all `.zip` archives and `*_frame_cache` folders.
- Older `Arcade_Combat_vX_Y_Z` version folders (git history replaces them; use tags from now on).

Keep these in a backup drive or cloud storage, or use Git LFS later.
